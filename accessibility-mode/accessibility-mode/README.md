# Accessibility Mode (Chrome / Edge / Brave)

Makes text HUGE on any website (default 250%, up to 500%), and adds high-contrast color themes,
bold text, wider spacing, underlined links, no animations and a big mouse pointer.

Install: chrome://extensions -> Developer mode -> Load unpacked -> pick this folder.
Reload tabs that were already open.

Shortcuts (change at chrome://extensions/shortcuts): Alt+Shift+A on/off, Alt+Shift+Up/Down text size.

Only text is enlarged; images stay the same size. Very large text can overflow fixed-size boxes on some
sites. Use the per-site off switch in the popup if a page breaks.
