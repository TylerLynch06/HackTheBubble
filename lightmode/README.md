# Lightmode (Chrome / Edge / Brave)

Turns the page black and lights only a soft circle around your cursor.

Install: chrome://extensions -> Developer mode -> Load unpacked -> pick this folder.
Reload tabs that were already open. Toggle with Alt+Shift+F (change it at chrome://extensions/shortcuts)
or from the toolbar popup, which also has beam size, soft edge, darkness, warm light and
a switch to hide the normal mouse pointer.

Works on http/https pages, not on chrome:// pages or the Web Store.

## Blinding light mode
Switch modes in the popup or with Alt+Shift+B. Instead of darkening the page, it floods it with white,
with a blazing glow around the cursor. The Brightness slider goes from a gentle wash to near-white.
It never flickers or flashes, but it is very bright: be careful in a dark room.
