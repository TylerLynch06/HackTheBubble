RAPID PAGE READER — INSTALLATION

1. Extract rapid_page_reader.zip to a folder.
2. Open Chrome and visit chrome://extensions
3. Turn on Developer mode (top-right).
4. Click "Load unpacked".
5. Select the extracted rapid_page_reader folder.
6. Open an ordinary web page, click the extension icon, then click "Read page".

SPEED
The default speed is 8.5×. Move the slider up to 10× for the fastest
rate exposed by Chrome's Text-to-Speech API. The actual spoken rate and
available voices depend on Chrome, the operating system, and installed voices.

CONTROLS
- Read page: extracts visible page text and starts speaking.
- Pause / Resume: pauses or continues speech.
- Stop: stops speech and clears the current reading queue.

NOTES
- Chrome restricts access to some pages, including chrome:// pages, the
  Chrome Web Store, and certain built-in PDF/document viewers.
- The extension uses Chrome's built-in TTS engine; it does not send page
  text to an external service.
- Very high speeds can reduce intelligibility. The rate slider can be
  adjusted while reading by stopping and starting again.
